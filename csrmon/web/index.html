What you get

A dashboard for your node

Sync state, tip, peers, CPU, memory and disk on one page. It runs on your own machine at 127.0.0.1 and is never opened to the internet.

Proof that it is a real full node

CSR proves your node's identity with its own P2P key. The monitor sends a signed challenge every 10 minutes and fetches blocks over P2P, so the ranking only counts nodes that hold the chain.

A seat in the revenue layer

Earn money by providing useful services for CKB Dapps, such as monitoring events, sending alerts, running oracles, automatically pushing due transactions and more.

How a node joins

  1. Install beside your node

    Windows or Linux. The installer finds your synced full node and proves its identity.

  2. The monitor checks it

    Every 10 minutes: a signed challenge on tip and block hashes. Once a day: blocks over P2P.

  3. Your node builds a record

    Provisional for 7 days, then ranked by availability over 30 and 365 days, sync and age.

  4. The gate opens

    With 20 ranked runners, 120 days of history and no single ASN or country in control, the Service Runtime starts on mainnet.

Install CSR

Windows

Windows 10 or 11, 64-bit · beta · this download is for Windows only

You need a synced CKB full node on the same PC: ckb.exe, or Neuron with its internal mainnet node. Neuron on testnet is a light client and cannot be used.

Download for Windows (latest)
  1. Unzip the file. Right-click the downloaded zip, choose Extract All. Do not run anything from inside the zip.
  2. Double-click install.cmd and allow the Administrator prompt. The beta is not code-signed, so SmartScreen may warn: click More info, then Run anyway.
  3. Let it find your node. The installer locates ckb.exe or Neuron's node, proves the node identity and asks you to choose a dashboard password.
  4. Open your dashboard. It opens in your browser at the end: 127.0.0.1:8140 for mainnet, :8130 for testnet. Later: Start menu, CSR, CSR Dashboard.
Check the download (optional)

In PowerShell, in your Downloads folder, compare the result with the line for csr-<version>-x86_64-windows.zip in SHA256SUMS of the latest release (same file, same hash). That file is signed with the CSR release key.

Get-FileHash .\csr-x86_64-windows.zip
Update or uninstall

Update: download the new zip and run its install.cmd. Settings, keys and data are kept.

Uninstall: run uninstall.cmd in C:\Program Files\csr. Add -RemoveData to delete the data and runner keys as well.

Keep the PC awake

The ranking measures availability. A PC that sleeps misses checks and drops in score. Set sleep to Never while plugged in.

Linux

Use the installer from the GitHub repository. It sets up one service per network and updates itself with signed releases.

sudo bash install.sh

Questions

Does it cost CKB?

The dashboard and the ranking are free. To run paid jobs later, a runner registers with a Nervos DAO deposit of at least 10,000 CKB, which stays yours and keeps earning DAO interest, plus about 700 CKB in the runner wallet for its registry cell and fees.

Can I earn CKB on mainnet today?

Not yet. On mainnet CSR runs as a node dashboard and builds your ranking. The Service Runtime opens when the gate above is met. On testnet you can already run jobs with test CKB.

What does the monitor publish about my node?

A runner ID, its score, availability, country and network operator (ASN). Never your IP address, city or exact location: map dots stand for 2° areas.

Does it open my node to the internet?

No. The dashboard listens only on your machine. CSR answers the monitor's checks, and behind a home router it connects out by itself.

Why does a full node matter?

Apps that hand work to independent nodes need nodes that hold the chain themselves. More independent full nodes also make the network harder to capture.
